由于使用了LFS处理大文件，因此要使用安装了Git LFS插件的git clone下载。
如果不想这么麻烦，在Releases有打包好的ZIP压缩包

开始界面：
点击“开始”进入角色选择界面

点击“设置”可以开关音乐、音效并调整大小。

点击左下角“重置”可以重置已解锁角色的信息（初始状态：300$，只解锁第一个拿刀的角色）


角色选择界面：

有三个角色可以选择：持刀近战（初始已解锁）、持枪（100$）、威力更大的枪（200$）
后两个拿枪角色需要购买解锁。理论上需要游玩获取钱，为了方便初始给了300$。

选择一名角色进入正式游戏界面。


正式游戏界面：

WASD移动，SHIFT翻滚，左键攻击。攻击到怪物有音效或特效（枪）。
有光圈的雕塑是“核心区”，初始血量100。
怪物从三个刷怪点出生，出生后向核心区移动，达到后发起攻击，核心区扣血，到0时游戏失败。
靠近三个造塔点（红圈处）会出现造塔界面，数字1、2、3对应三种塔，造好塔后可以按空格键升级。满级后不再出现造塔界面。防御塔会自动攻击附近的怪物。
击杀怪物得钱，造塔花钱。为了方便初始给了100。
击杀所有怪物后游戏胜利。
按ESC回到开始界面。
